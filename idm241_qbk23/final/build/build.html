Move the cursor onto the image card. Click the Board button to pick, search or create a board, or click Save. Use "Undo" in the Saved message, or click "Saved", to remove the save.

COMPARE WITH THE ORIGINAL:

pinterest.com →

To compare: log in to Pinterest, stay on the Home feed, move the cursor onto any image card, and click its Board button or Save button.

What this Final Build improves

  • Timed transitions: on Pinterest every visual change is instant (0 seconds). Here, only the cursor changes instantly; everything else fades, slides or grows over 0.1 to 0.2 seconds.
  • Saved message with "Undo": after a save, a message slides up with an "Undo" button and a 4-second timer bar that pauses while the cursor is on it.
  • Undo from the button: clicking "Saved" removes the save.
  • Search and "Create board": typing filters the boards, and a new board can be named and saved to without leaving the image card.
  • Kept after a reload: saves and new boards are kept in the database (localStorage).

TERMS:

Image card
One image in the Pinterest Home feed. (Pinterest calls this a "pin.")
Board
A named collection of saved image cards, like a folder. Example: "Andys."
Board button
Button in the top-left corner of the image card. Contains the board name and a down arrow.
Save button
Red button in the top-right corner of the image card.
Board picker window
White window titled "Save" that slides down when the Board button is clicked. Lists the user's boards.
Board row
One line in the board picker window: a board's small image and its name.
Row Save button
Red "Save" button on the right side of a board row.
"Create board" row
Last line of the board picker window. Clicking it lets the user name and make a new board.
Saved message
Black box that slides up at the bottom of the browser window after a save. Reads "Saved to" and the board name.
Timer bar
Thin red bar along the bottom of the Saved message. Its width shrinks as the 4 seconds run out.
"Undo" button
White button in the Saved message. Clicking it removes the save.
Database
Where saves are kept. In my build it is the browser's localStorage, so a save is kept after a reload.
Opacity
How visible something is: 0% is invisible, 100% is fully visible.
Transition
A gradual change from one state to another over a set time, in seconds.
Fade in / fade out
Opacity transitions from 0% to 100% (fade in) or from 100% to 0% (fade out).
Cross-fade
One thing fades out while another fades in, in the same spot.

LOOPS & MODES:

  • Search Mode (user types in the search bar)
    • Gray hint text "Search" fades out when the first letter is typed: opacity transitions from 100% to 0% over 0.15 seconds
    • Board rows whose names do not contain the typed text fade out while their height shrinks to 0, over 0.15 seconds; the rows below slide up to close the space
    • "Top choices" and "All boards" labels fade out and shrink the same way
    • If no board names match, the text "No boards found" fades in while its space grows open, over 0.15 seconds
    • Deleting typed letters runs these transitions in reverse
  • Timer Loop (the Saved message)
    • Each save starts a 4-second timer, shown by the red timer bar shrinking from 100% to 0% width
    • Hover ON or keyboard focus pauses the timer; Hover OFF continues it from where it stopped
    • A new save while the Saved message is up refills the timer bar (0.15 seconds) and starts the 4 seconds again
    • "Undo" and Save Button Click OFF end the timer early: the Saved message slides back down over 0.15 seconds
  • Picker Reset (after the board picker window has finished sliding up and is fully out of view)
    • Its search bar is emptied and the "Create board" form is put back to the "Create board" row, so the window always slides down in the same starting state
  • Saved Mode (after a Board Row, "Create" or Save button Click ON)
    • Save button stays BLACK with "Saved", and the board name stays underlined with no down arrow
    • Board button still works: Click ON slides the board picker window down, and choosing a different board moves the save to that board
    • Saved Mode ends only when the user clicks "Saved" (Save Button Click OFF)
  • Page Reload
    • The page loads already in the last state kept in the database (localStorage): "Save" or "Saved", the last board name, and any boards the user created
  • Keyboard Mode (user presses Tab to move between buttons)
    • A blue outline fades in around the selected button or link: outline color transitions from transparent to blue (#435EE5) over 0.15 seconds
    • The image card's dark gradient layer, Board button and Save button fade in, the same as Image Card Hover ON
    • Enter or Space works the same as Click ON
  • Touch Mode (phones and tablets, which have no hover)
    • Dark gradient layer, Board button, Save button and every Row Save button stay at 100% opacity; the Saved message timer cannot be paused, so it always runs the full 4 seconds
  • Reduced Motion Mode (the user's device is set to reduce motion)
    • Board picker window and Saved message fade in and out in place, without sliding
    • Every other transition keeps its timing
