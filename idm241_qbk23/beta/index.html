IDM 241 · Beta Microinteractions

URL

https://www.pinterest.com/

Objects: Board Button, Board Row, Save Button

My Beta builds on my Alpha (the Save button) by adding the Board button and the board picker window, so the user can choose which board an image is saved to.

On Pinterest, every change below happens instantly (in 0 seconds, with no animation). In my Beta, each change takes a set amount of time (a fade or a slide) so it is easier to follow. The colors and sizes come from Pinterest.

Terms used on this page

Home feed
The main Pinterest page you see after logging in: a grid of images.
Image card
One image in the Home feed. (Pinterest calls this a "pin.")
Board
A named collection of saved image cards, like a folder. Example: "Plugg."
Board button
Button in the top-left corner of an image card. Shows the board name and a down arrow.
Save button
Red button in the top-right corner of an image card.
Board picker window
Window titled "Save" that opens when the Board button is clicked. Lists the user's boards.
Board row
One line in the board picker window: a board's small image and its name.
Row Save button
Red "Save" button on the right side of a board row.
Opacity
How visible something is: 0% is invisible, 100% is fully visible.

How to find them

Log in to Pinterest and stay on the Home feed. Move the cursor onto any image card to see the Board button in its top-left corner and the Save button in its top-right corner. Click the Board button to open the board picker window, which has one board row for each board.

TRIGGERS:

  • Board Button
    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON
    • Hover OFF
    • Click ON
    • Click OFF (click outside the board picker window, or press the Esc key)
  • Board Row
    • Hover ON
    • Hover OFF
    • Click ON (Row Save button)
  • Save Button
    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON
    • Hover OFF
    • Click ON

RULES:

  • Board Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Dark gradient layer fades in over the image card
        • Black at 40% opacity at the top, fading to 0% opacity at the bottom
        • Opacity changes from 0% to 100% over 0.15 seconds
      • Board button fades in at the top-left corner of the image card
        • Shows the board name (example: "Plugg") and a down arrow, in white text
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Dark gradient layer and Board button fade out
        • Opacity changes from 100% to 0% over 0.15 seconds
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Rounded background fades in behind the board name and down arrow
        • Near-black at 50% opacity, with 16px rounded corners
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Rounded background fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
    • Click ON
      • Board picker window slides down from the top, just below the Board button
        • Starts 8px higher than its final position, at 0% opacity
        • Moves down 8px while opacity changes from 0% to 100% over 0.2 seconds
      • Board picker window shows, from top to bottom:
        • Title "Save"
        • Search bar, with a blinking text cursor in it
        • "Top choices" list of recently used boards
        • "All boards" list, which scrolls up and down
        • "Create board" button
      • Board button's rounded background stays at 100% opacity while the board picker window is open
    • Click OFF (click outside the board picker window, or press the Esc key)
      • Board picker window slides back up and fades out
        • Moves up 8px while opacity changes from 100% to 0% over 0.15 seconds
      • Board button's rounded background fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
  • Board Row:
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Board row background changes from white to light gray (#E5E5E0) over 0.1 seconds
        • 12px rounded corners
      • Row Save button fades in on the right side of the board row
        • Red (#E60023) with white "Save" text
        • Opacity changes from 0% to 100% over 0.1 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Board row background changes from light gray back to white over 0.1 seconds
      • Row Save button fades out
        • Opacity changes from 100% to 0% over 0.1 seconds
    • Click ON (Row Save button)
      • Image card is saved to that board
      • Database updated with the image card added to that board
      • Board picker window slides back up and fades out
        • Moves up 8px while opacity changes from 100% to 0% over 0.15 seconds
      • Board button text changes to the chosen board's name
      • Save button background changes from RED to BLACK over 0.15 seconds
      • Save button text changes from "Save" to "Saved"
      • Down arrow on the Board button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Board name becomes underlined (it is now a link to that board)
      • That board becomes the default board for the next save
  • Save Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Save button fades in at the top-right corner of the image card
        • Red (#E60023) with white "Save" text, 16px rounded corners
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Save button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Background changes from red (#E60023) to darker red (#CC001F) over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Background changes from darker red (#CC001F) back to red (#E60023) over 0.15 seconds
    • Click ON
      • Image card is saved to the board shown on the Board button
      • Database updated with the image card added to that board
      • Background changes from RED to BLACK over 0.15 seconds
      • Text changes from "Save" to "Saved"
      • Down arrow on the Board button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Board name becomes underlined (it is now a link to that board)
      • That board stays the default board for the next save
