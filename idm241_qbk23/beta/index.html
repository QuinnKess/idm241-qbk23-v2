URL

https://www.pinterest.com/

Objects: Board Button, Board Row, Save Button

The Beta builds on my Alpha (the Save button) by adding the Board button and the "Save" board picker window, so the user can choose which board a pin is saved to.

How to find them: log in to Pinterest, stay on the Home feed, and move the mouse over any pin. The Board button (board name and down arrow) appears in the top-left corner and the red Save button appears in the top-right corner. Clicking the Board button opens the board picker, which lists a Board Row for each board.

TRIGGERS:

  • Board Button
    • Hover ON
    • Hover OFF
    • Click ON
    • Click OFF (Esc key or click outside the window)
  • Board Row
    • Hover ON
    • Hover OFF
    • Click ON (row's Save button)
  • Save Button
    • Hover ON
    • Hover OFF
    • Click ON

RULES:

  • Board Button:
    • Hover ON
      • Cursor changes to Finger
      • Dark gray rounded background appears behind the board name and down arrow
    • Hover OFF
      • Cursor changes back to default
      • Dark gray background disappears
    • Click ON
      • "Save" board picker window opens below the Board button
        • Title "Save" at the top
        • Search bar, with the text cursor blinking in it
        • "Top choices" list of recent boards
        • "All boards" list that scrolls
        • "Create board" button at the bottom
      • Board button stays dark gray while the window is open
    • Click OFF
      • Board picker window closes
      • Board button goes back to normal
  • Board Row:
    • Hover ON
      • Cursor changes to Finger
      • Row background turns light gray
      • Red "Save" button appears on the right side of the row
    • Hover OFF
      • Cursor changes back to default
      • Light gray background disappears
      • Row's "Save" button disappears
    • Click ON
      • Pin is saved to that board
      • Database updated with the pin added to that board
      • Board picker window closes
      • Board button text changes to that board's name
      • Pin's Save button changes from RED to BLACK
      • Pin's Save button text "Save" changes to "Saved"
      • Down arrow on the Board button disappears
      • Board name becomes an underlined link to the board
      • That board becomes the default board for the next save
  • Save Button:
    • Hover ON
      • Cursor changes to Finger
      • Button turns a darker red
    • Hover OFF
      • Cursor changes back to default
      • Button goes back to normal red
    • Click ON
      • Pin is saved to the board shown on the Board button
      • Database updated with the pin added to that board
      • Button background changes from RED to BLACK
      • Button text "Save" changes to "Saved"
      • Down arrow on the Board button disappears
      • Board name becomes an underlined link to the board
      • That board stays the default board for the next save
