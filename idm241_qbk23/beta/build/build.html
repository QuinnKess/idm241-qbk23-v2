Move the cursor onto the image card. Click the Board button to pick or create a board, or click Save. Click "Saved" to undo.

TERMS:

Image card
One image in the Pinterest Home feed. (Pinterest calls this a "pin.")
Board
A named collection of saved image cards, like a folder. Example: "Andys."
Board button
Button in the top-left corner of the image card. Contains the board name and a down arrow.
Save button
Red button in the top-right corner of the image card.
Board picker window
White window titled "Save" that slides down when the Board button is clicked. Lists the user's boards.
Board row
One line in the board picker window: a board's small image and its name.
Row Save button
Red "Save" button on the right side of a board row.
"Create board" row
Last line of the board picker window. Clicking it lets the user name and make a new board.
Database
Where saves are kept. In this build it is the browser's localStorage, so a save is kept after a reload.
Opacity
How visible something is: 0% is invisible, 100% is fully visible.
Transition
A gradual change from one state to another over a set time, in seconds.
Fade in / fade out
Opacity transitions from 0% to 100% (fade in) or from 100% to 0% (fade out).
Cross-fade
One thing fades out while another fades in, in the same spot.

Original: pinterest.com. On Pinterest every visual change is instant (0 seconds). In this Beta, only the cursor changes instantly; everything else transitions over 0.1 to 0.2 seconds so it is easier to follow.

    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON
    • Hover OFF
    • Click ON
    • Click OFF (click the Board button again, click outside the board picker window, or press the Esc key)
  • Board Row
    • Hover ON
    • Hover OFF
    • Click ON (anywhere on the board row, including the Row Save button)
    • "Create board" Row Hover ON
    • "Create board" Row Hover OFF
    • "Create board" Row Click ON
    • Typing a board name
    • "Create" Button Click ON (or press Enter in the text field)
  • Save Button
    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON (button reads "Save")
    • Hover ON (button reads "Saved")
    • Hover OFF
    • Click ON (button reads "Save")
    • Click OFF (button reads "Saved")

RULES:

  • Board Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Dark gradient layer fades in over the image card
        • Black at 40% opacity at the top, graduating to 0% opacity at the bottom
        • Opacity transitions from 0% to 100% over 0.15 seconds
      • Board button fades in at the top-left corner of the image card
        • Contains a board name ("Andys" the first time) and a down arrow, in white text
        • Opacity transitions from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Dark gradient layer and Board button fade out
        • Opacity transitions from 100% to 0% over 0.15 seconds
      • While the board picker window is open, they stay at 100% opacity until it slides back up
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Rounded background fades in behind the board name and down arrow
        • 16px rounded corners
        • Background color transitions from transparent to near-black at 50% opacity over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Rounded background fades out
        • Background color transitions from near-black at 50% opacity to transparent over 0.15 seconds
      • While the board picker window is open, the rounded background stays at 100% opacity until it slides back up
    • Click ON
      • Board picker window slides down from the top, just below the Board button
        • Starts 8px above its final position, at 0% opacity
        • Moves down 8px while its opacity transitions from 0% to 100% over 0.2 seconds
      • Board picker window contains, from top to bottom:
        • Title "Save"
        • Search bar with the gray hint text "Search"
        • "Top choices" list: Andys, Plugg
        • "All boards" list: any boards the user created, then Amazing minecraft, Andys, Plugg (scrolls up and down)
        • "Create board" row
      • Search bar is selected
        • Search bar border color transitions from light gray (#CCCCCC) to blue (#435EE5) over 0.15 seconds
        • Blinking text cursor is placed in the search bar
    • Click OFF (click the Board button again, click outside the board picker window, or press the Esc key)
      • Board picker window slides back up and fades out
        • Moves up 8px while its opacity transitions from 100% to 0% over 0.15 seconds
      • Board button's rounded background fades out
        • Background color transitions from near-black at 50% opacity to transparent over 0.15 seconds
  • Board Row:
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Board row background color transitions from white to light gray (#E5E5E0) over 0.1 seconds
        • 12px rounded corners
      • Row Save button fades in on the right side of the board row
        • Red (#E60023) with white "Save" text
        • Opacity transitions from 0% to 100% over 0.1 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Board row background color transitions from light gray back to white over 0.1 seconds
      • Row Save button fades out
        • Opacity transitions from 100% to 0% over 0.1 seconds
    • Click ON (anywhere on the board row, including the Row Save button)
      • Image card is saved to that board (if it was saved to a different board, it moves to this one)
      • Database updated (in this build, the browser's localStorage, so it is kept after the page is reloaded)
      • That board becomes the default board for the next save
      • Board picker window slides back up and fades out
        • Moves up 8px while its opacity transitions from 100% to 0% over 0.15 seconds
      • If the board name is different, the board name cross-fades to the new name
        • Old board name fades out: opacity transitions from 100% to 0% over 0.15 seconds
        • Then the Board button's width transitions to fit the new name while the new name fades in (opacity 0% to 100%), over 0.15 seconds
      • Save button background color transitions from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • "Save" text fades out while "Saved" text fades in, in the same spot
        • Both opacity transitions take 0.15 seconds, so the button does not change size
      • Down arrow on the Board button fades out
        • Opacity transitions from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Underline color transitions from transparent to white over 0.15 seconds
      • If the image card was already saved, the Save button, down arrow and underline stay as they are and only the board name cross-fades
    • "Create board" Row Hover ON
      • Cursor changes from arrow to pointing finger
      • Row background color transitions from white to light gray (#E5E5E0) over 0.1 seconds
    • "Create board" Row Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Row background color transitions from light gray back to white over 0.1 seconds
    • "Create board" Row Click ON
      • "Create board" row fades out while a form fades in, in the same spot
        • Both opacity transitions take 0.1 seconds
        • Form contains a text field with the gray hint text "Board name", and a "Create" button
        • "Create" button is gray (#E9E9E9) with gray text, and clicking it does nothing
      • Text field is selected
        • Text field border color transitions from light gray (#CCCCCC) to blue (#435EE5) over 0.15 seconds
        • Blinking text cursor is placed in the text field
    • Typing a board name
      • Gray hint text "Board name" fades out when the first letter is typed
        • Opacity transitions from 100% to 0% over 0.15 seconds
      • "Create" button background color transitions from gray to red (#E60023), and its text color from gray to white, over 0.1 seconds
      • If every letter is deleted, the hint text fades back in and the "Create" button transitions back to gray (0.15 and 0.1 seconds)
    • "Create" Button Click ON (or press Enter in the text field)
      • New board added to the database
      • Image card is saved to the new board
      • The new board becomes the default board for the next save
      • New board row grows in at the top of the "All boards" list
        • Its height transitions from 0 to full height while its opacity transitions from 0% to 100%, over 0.2 seconds
        • Contains a gray square with the board's first letter, and the board name
      • If a board with that name already exists, no new row grows in; the image card is saved to the existing board
      • Board picker window slides back up and fades out
        • Moves up 8px while its opacity transitions from 100% to 0% over 0.15 seconds
      • If the board name is different, the board name cross-fades to the new name
        • Old board name fades out: opacity transitions from 100% to 0% over 0.15 seconds
        • Then the Board button's width transitions to fit the new name while the new name fades in (opacity 0% to 100%), over 0.15 seconds
      • Save button background color transitions from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • "Save" text fades out while "Saved" text fades in, in the same spot
        • Both opacity transitions take 0.15 seconds, so the button does not change size
      • Down arrow on the Board button fades out
        • Opacity transitions from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Underline color transitions from transparent to white over 0.15 seconds
      • If the image card was already saved, the Save button, down arrow and underline stay as they are and only the board name cross-fades
  • Save Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Save button fades in at the top-right corner of the image card
        • Red (#E60023) with white "Save" text, 16px rounded corners
        • Opacity transitions from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Save button fades out
        • Opacity transitions from 100% to 0% over 0.15 seconds
    • Hover ON (button reads "Save")
      • Cursor changes from arrow to pointing finger
      • Background color transitions from red (#E60023) to darker red (#CC001F) over 0.15 seconds
    • Hover ON (button reads "Saved")
      • Cursor changes from arrow to pointing finger
      • Background color transitions from black (#111111) to dark gray (#333333) over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Background color transitions back to red (#E60023), or to black (#111111) if the button reads "Saved", over 0.15 seconds
    • Click ON (button reads "Save")
      • Image card is saved to the board on the Board button
      • Database updated (in this build, the browser's localStorage, so it is kept after the page is reloaded)
      • If the board picker window is open, it slides back up and fades out (moves up 8px while its opacity transitions from 100% to 0% over 0.15 seconds)
      • Save button background color transitions from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • "Save" text fades out while "Saved" text fades in, in the same spot
        • Both opacity transitions take 0.15 seconds, so the button does not change size
      • Down arrow on the Board button fades out
        • Opacity transitions from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Underline color transitions from transparent to white over 0.15 seconds
    • Click OFF (button reads "Saved")
      • Image card is removed from the board
      • Database updated (in this build, the browser's localStorage, so it is kept after the page is reloaded)
      • Save button background color transitions from BLACK (#111111) to RED (#E60023) over 0.15 seconds
      • "Saved" text fades out while "Save" text fades in, in the same spot
        • Both opacity transitions take 0.15 seconds
      • Down arrow on the Board button fades in

LOOPS & MODES:

  • Search Mode (user types in the search bar)
    • Gray hint text "Search" fades out when the first letter is typed: opacity transitions from 100% to 0% over 0.15 seconds
    • Board rows whose names do not contain the typed text fade out while their height shrinks to 0, over 0.15 seconds; the rows below slide up to close the space
    • "Top choices" and "All boards" labels fade out and shrink the same way
    • If no board names match, the text "No boards found" fades in while its space grows open, over 0.15 seconds
    • Deleting typed letters runs these transitions in reverse
  • Picker Reset (after the board picker window has finished sliding up and is fully out of view)
    • Its search bar is emptied and the "Create board" form is put back to the "Create board" row, so the window always slides down in the same starting state
  • Saved Mode (after a Board Row, "Create" or Save button Click ON)
    • Save button stays BLACK with "Saved", and the board name stays underlined with no down arrow
    • Board button still works: Click ON slides the board picker window down, and choosing a different board moves the save to that board
    • Saved Mode ends only when the user clicks "Saved" (Save Button Click OFF)
  • Page Reload
    • The page loads already in the last state kept in the database (localStorage): "Save" or "Saved", the last board name, and any boards the user created
  • Keyboard Mode (user presses Tab to move between buttons)
    • A blue outline fades in around the selected button or link: outline color transitions from transparent to blue (#435EE5) over 0.15 seconds
    • The image card's dark gradient layer, Board button and Save button fade in, the same as Image Card Hover ON
    • Enter or Space works the same as Click ON
  • Touch Mode (phones and tablets, which have no hover)
    • Dark gradient layer, Board button, Save button and every Row Save button stay at 100% opacity
  • Reduced Motion Mode (the user's device is set to reduce motion)
    • Board picker window fades in and out in place, without sliding up or down
    • Every other transition keeps its timing
