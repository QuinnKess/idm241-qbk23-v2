Move the cursor onto the image card. Click the Board button to pick or create a board, or click Save. Click "Saved" to undo.

TERMS:

Image card
One image in the Pinterest Home feed. (Pinterest calls this a "pin.")
Board
A named collection of saved image cards, like a folder. Example: "Andys."
Board button
Button in the top-left corner of the image card. Shows the board name and a down arrow.
Save button
Red button in the top-right corner of the image card.
Board picker window
White window titled "Save" that opens when the Board button is clicked. Lists the user's boards.
Board row
One line in the board picker window: a board's small image and its name.
Row Save button
Red "Save" button on the right side of a board row.
"Create board" row
Last line of the board picker window. Clicking it lets the user name and make a new board.
Database
Where saves are stored. In this build it is the browser's localStorage, so a save is still there after a reload.
Opacity
How visible something is: 0% is invisible, 100% is fully visible.

Original: pinterest.com. On Pinterest every change is instant (0 seconds). In this Beta, each change takes 0.1 to 0.2 seconds so it is easier to follow.

TRIGGERS:

  • Board Button
    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON
    • Hover OFF
    • Click ON
    • Click OFF (click the Board button again, click outside the board picker window, or press the Esc key)
  • Board Row
    • Hover ON
    • Hover OFF
    • Click ON (anywhere on the board row, including the Row Save button)
    • "Create board" Row Hover ON
    • "Create board" Row Hover OFF
    • "Create board" Row Click ON
    • Typing a board name
    • "Create" Button Click ON (or press Enter in the text field)
  • Save Button
    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON (button says "Save")
    • Hover ON (button says "Saved")
    • Hover OFF
    • Click ON (button says "Save")
    • Click OFF (button says "Saved")

RULES:

  • Board Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Dark gradient layer fades in over the image card
        • Black at 40% opacity at the top, fading to 0% opacity at the bottom
        • Opacity changes from 0% to 100% over 0.15 seconds
      • Board button fades in at the top-left corner of the image card
        • Shows a board name ("Andys" the first time) and a down arrow, in white text
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Dark gradient layer and Board button fade out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • If the board picker window is open, they stay at 100% opacity until it closes
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Rounded background fades in behind the board name and down arrow
        • Near-black at 50% opacity, with 16px rounded corners
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Rounded background fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • If the board picker window is open, the rounded background stays at 100% opacity until it closes
    • Click ON
      • Board picker window slides down from the top, just below the Board button
        • Starts 8px higher than its final position, at 0% opacity
        • Moves down 8px while opacity changes from 0% to 100% over 0.2 seconds
      • Board picker window shows, from top to bottom:
        • Title "Save"
        • Search bar (empty), with a blinking text cursor in it
        • "Top choices" list: Andys, Plugg
        • "All boards" list: any boards the user created, then Amazing minecraft, Andys, Plugg (scrolls up and down)
        • "Create board" row at the bottom
    • Click OFF (click the Board button again, click outside the board picker window, or press the Esc key)
      • Board picker window slides back up and fades out
        • Moves up 8px while opacity changes from 100% to 0% over 0.15 seconds
      • Board button's rounded background fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
  • Board Row:
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Board row background changes from white to light gray (#E5E5E0) over 0.1 seconds
        • 12px rounded corners
      • Row Save button fades in on the right side of the board row
        • Red (#E60023) with white "Save" text
        • Opacity changes from 0% to 100% over 0.1 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Board row background changes from light gray back to white over 0.1 seconds
      • Row Save button fades out
        • Opacity changes from 100% to 0% over 0.1 seconds
    • Click ON (anywhere on the board row, including the Row Save button)
      • Image card is saved to that board (if it was saved to a different board, it moves to this one)
      • Database updated (in this build, the browser's localStorage, so the change is still there after the page is reloaded)
      • That board becomes the default board for the next save
      • Board picker window slides back up and fades out
        • Moves up 8px while opacity changes from 100% to 0% over 0.15 seconds
      • Board button text changes to that board's name
      • Save button background changes from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • Save button text changes from "Save" to "Saved"
      • Down arrow on the Board button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Opacity changes from 0% to 100% over 0.15 seconds
    • "Create board" Row Hover ON
      • Cursor changes from arrow to pointing finger
      • Row background changes from white to light gray (#E5E5E0) over 0.1 seconds
    • "Create board" Row Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Row background changes from light gray back to white over 0.1 seconds
    • "Create board" Row Click ON
      • "Create board" row is replaced by a form (instantly, 0 seconds)
        • Text field with the gray hint "Board name" and a blinking text cursor in it
        • "Create" button on the right: gray (#E9E9E9) with gray text, and clicking it does nothing
    • Typing a board name
      • "Create" button background changes from gray to red (#E60023) and its text from gray to white over 0.1 seconds
      • If the text field is emptied again, the "Create" button changes back to gray over 0.1 seconds
    • "Create" Button Click ON (or press Enter in the text field)
      • New board added to the database
      • Image card is saved to the new board
      • The new board becomes the default board for the next save
      • New board row is added at the top of the "All boards" list (instantly, 0 seconds)
        • Shows a gray square with the board's first letter, and the board name
      • If a board with that name already exists, no new row is added; the image card is saved to the existing board
      • Board picker window slides back up and fades out
        • Moves up 8px while opacity changes from 100% to 0% over 0.15 seconds
      • Board button text changes to that board's name
      • Save button background changes from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • Save button text changes from "Save" to "Saved"
      • Down arrow on the Board button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Opacity changes from 0% to 100% over 0.15 seconds
  • Save Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Save button fades in at the top-right corner of the image card
        • Red (#E60023) with white "Save" text, 16px rounded corners
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Save button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
    • Hover ON (button says "Save")
      • Cursor changes from arrow to pointing finger
      • Background changes from red (#E60023) to darker red (#CC001F) over 0.15 seconds
    • Hover ON (button says "Saved")
      • Cursor changes from arrow to pointing finger
      • Background changes from black (#111111) to dark gray (#333333) over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Background changes back to red (#E60023), or black (#111111) if it says "Saved", over 0.15 seconds
    • Click ON (button says "Save")
      • Image card is saved to the board shown on the Board button
      • Database updated (in this build, the browser's localStorage, so the change is still there after the page is reloaded)
      • If the board picker window is open, it slides back up and fades out (moves up 8px while opacity changes from 100% to 0% over 0.15 seconds)
      • Save button background changes from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • Save button text changes from "Save" to "Saved"
      • Down arrow on the Board button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Click OFF (button says "Saved")
      • Image card is removed from the board
      • Database updated (in this build, the browser's localStorage, so the change is still there after the page is reloaded)
      • Save button background changes from BLACK (#111111) to RED (#E60023) over 0.15 seconds
      • Save button text changes from "Saved" to "Save"
      • Down arrow on the Board button fades in
        • Opacity changes from 0% to 100% over 0.15 seconds
      • Underline under the board name fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Board button keeps the same board name, so the next Click ON saves to that board again

LOOPS & MODES:

  • Search Mode (user types in the search bar)
    • Board rows whose names do not contain the typed text are hidden (instantly, 0 seconds)
    • "Top choices" and "All boards" labels are hidden while there is text in the search bar
    • If no board names match, the text "No boards found" shows instead (instantly, 0 seconds)
    • Search bar is emptied, and the "Create board" form goes back to the "Create board" row, every time the board picker window opens
  • Saved Mode (after a Board Row, "Create" or Save button Click ON)
    • Save button stays BLACK with "Saved" and the board name stays underlined with no down arrow
    • Board button still works: Click ON opens the board picker window, and choosing a different board moves the save to that board
    • Saved Mode ends only when the user clicks "Saved" (Save Button Click OFF)
  • Page Reload
    • The page reads the database (localStorage) and shows the last state right away, with no animation: "Save" or "Saved", the last board name, and any boards the user created
  • Touch Mode (phones and tablets, which have no hover)
    • Dark gradient layer, Board button, Save button and every Row Save button stay at 100% opacity
  • Reduced Motion Mode (the user's device is set to reduce motion)
    • Every change happens instantly (0 seconds) instead of fading or sliding
