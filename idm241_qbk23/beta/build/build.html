Move the cursor onto the image card. Click the Board button to pick a board, or click Save.

TERMS:

Image card
One image in the Pinterest Home feed. (Pinterest calls this a "pin.")
Board
A named collection of saved image cards, like a folder. Example: "Andys."
Board button
Button in the top-left corner of the image card. Shows the board name and a down arrow.
Save button
Red button in the top-right corner of the image card.
Board picker window
White window titled "Save" that opens when the Board button is clicked. Lists the user's boards.
Board row
One line in the board picker window: a board's small image and its name.
Row Save button
Red "Save" button on the right side of a board row.
Opacity
How visible something is: 0% is invisible, 100% is fully visible.

Original: pinterest.com. On Pinterest every change is instant (0 seconds). In this Beta, each change takes 0.1 to 0.2 seconds so it is easier to follow.

TRIGGERS:

  • Board Button
    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON
    • Hover OFF
    • Click ON
    • Click OFF (click the Board button again, click outside the board picker window, or press the Esc key)
  • Board Row
    • Hover ON
    • Hover OFF
    • Click ON (anywhere on the board row, including the Row Save button)
  • Save Button
    • Image Card Hover ON (cursor moves onto the image card)
    • Image Card Hover OFF (cursor moves off the image card)
    • Hover ON
    • Hover OFF
    • Click ON

RULES:

  • Board Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Dark gradient layer fades in over the image card
        • Black at 40% opacity at the top, fading to 0% opacity at the bottom
        • Opacity changes from 0% to 100% over 0.15 seconds
      • Board button fades in at the top-left corner of the image card
        • Shows the board name ("Andys") and a down arrow, in white text
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Dark gradient layer and Board button fade out
        • Opacity changes from 100% to 0% over 0.15 seconds
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Rounded background fades in behind the board name and down arrow
        • Near-black at 50% opacity, with 16px rounded corners
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Rounded background fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
    • Click ON
      • Board picker window slides down from the top, just below the Board button
        • Starts 8px higher than its final position, at 0% opacity
        • Moves down 8px while opacity changes from 0% to 100% over 0.2 seconds
      • Board picker window shows, from top to bottom:
        • Title "Save"
        • Search bar, with a blinking text cursor in it
        • "Top choices" list: Andys, Plugg
        • "All boards" list: Amazing minecraft, Andys, Plugg (scrolls up and down)
        • "Create board" row at the bottom
      • Board button's rounded background and the dark gradient layer stay at 100% opacity while the board picker window is open
    • Click OFF (click the Board button again, click outside the board picker window, or press the Esc key)
      • Board picker window slides back up and fades out
        • Moves up 8px while opacity changes from 100% to 0% over 0.15 seconds
      • Board button's rounded background fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
  • Board Row:
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Board row background changes from white to light gray (#E5E5E0) over 0.1 seconds
        • 12px rounded corners
      • Row Save button fades in on the right side of the board row
        • Red (#E60023) with white "Save" text
        • Opacity changes from 0% to 100% over 0.1 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Board row background changes from light gray back to white over 0.1 seconds
      • Row Save button fades out
        • Opacity changes from 100% to 0% over 0.1 seconds
    • Click ON (anywhere on the board row, including the Row Save button)
      • Image card is saved to that board
      • Database updated with the image card added to that board (in this build, a JavaScript variable stores the board name)
      • Board picker window slides back up and fades out
        • Moves up 8px while opacity changes from 100% to 0% over 0.15 seconds
      • Board button text changes to the chosen board's name
      • Save button background changes from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • Save button text changes from "Save" to "Saved"
      • Down arrow on the Board button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Opacity changes from 0% to 100% over 0.15 seconds
  • Save Button:
    • Image Card Hover ON (cursor moves onto the image card)
      • Save button fades in at the top-right corner of the image card
        • Red (#E60023) with white "Save" text, 16px rounded corners
        • Opacity changes from 0% to 100% over 0.15 seconds
    • Image Card Hover OFF (cursor moves off the image card)
      • Save button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
    • Hover ON
      • Cursor changes from arrow to pointing finger
      • Background changes from red (#E60023) to darker red (#CC001F) over 0.15 seconds
    • Hover OFF
      • Cursor changes from pointing finger back to arrow
      • Background changes from darker red (#CC001F) back to red (#E60023) over 0.15 seconds
    • Click ON
      • Image card is saved to the board shown on the Board button (Andys)
      • Database updated with the image card added to that board (in this build, a JavaScript variable stores the board name)
      • Save button background changes from RED (#E60023) to BLACK (#111111) over 0.15 seconds
      • Save button text changes from "Save" to "Saved"
      • Down arrow on the Board button fades out
        • Opacity changes from 100% to 0% over 0.15 seconds
      • Underline fades in under the board name
        • Opacity changes from 0% to 100% over 0.15 seconds

LOOPS & MODES:

  • Search Mode (user types in the search bar)
    • Board rows whose names do not match the typed text are hidden (instantly, 0 seconds)
    • "Top choices" and "All boards" labels are hidden while there is text in the search bar
    • If no board names match, the text "No boards found" shows instead
    • Search bar is emptied every time the board picker window opens
  • Saved Mode (after a Save button or board row Click ON)
    • Save button stays BLACK with "Saved", even on Hover ON; cursor stays an arrow
    • Board button stays underlined with no down arrow; Hover ON no longer shows the rounded background, and Click ON no longer opens the board picker window
    • Saved Mode lasts until the page is reloaded, which resets the image card to "Save" and "Andys"
  • Touch Mode (phones and tablets, which have no hover)
    • Dark gradient layer, Board button, Save button and every Row Save button stay at 100% opacity
