IDM 241 · Alpha Microinteraction

URL

https://www.pinterest.com/

Object: Save Button

How to find it: log in to Pinterest, stay on the Home feed, and move the mouse over any pin. The red "Save" button appears in the top-right corner of the pin.

TRIGGERS:

  • Pin
    • Hover ON
    • Hover OFF
  • Board Button
    • Hover ON
    • Hover OFF
  • Save Button
    • Hover ON
    • Hover OFF
    • Click ON

RULES:

  • Pin:
    • Hover ON
      • Dark gray overlay appears over the pin image
      • Board button appears top left
        • Shows the board name (example: "Plugg") and a down arrow
      • Red "Save" button appears top right
      • Share icon appears bottom right
        • White rounded square, black arrow
    • Hover OFF
      • Overlay disappears
      • Board button, Save button and share icon disappear
  • Board Button:
    • Hover ON
      • Cursor changes to Finger
      • Dark gray rounded background appears behind the board name and down arrow
    • Hover OFF
      • Cursor changes back to default
      • Dark gray background disappears
  • Save Button:
    • Hover ON
      • Cursor changes to Finger
      • Button turns a darker red
    • Hover OFF
      • Cursor changes back to default
      • Button goes back to normal red
    • Click ON
      • Pin is saved to the board shown on the Board button
      • Database updated with the pin added to that board
      • Button background changes from RED to BLACK
      • Button text "Save" changes to "Saved"
      • Down arrow on the Board button disappears
      • Board name becomes an underlined link to the board
      • That board stays the default board for the next save
